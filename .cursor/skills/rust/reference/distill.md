# /rust-skills:rust distill [target] — 精简到本质

目的：在**行为不变**的前提下删抽象、删代码、去仪式，并对旧模块走 WS-11 结构梯子（SIMP 域的执行命令）。这就是「优化旧代码」的入口，**不要另开 `/optimize` 或 `/split`**。缺省 target = 最近改动；优化遗留必须点路径，「全仓」须显式。裸调用只列候选；`--apply` 或明确写入授权后才改码。crate 边界只出建议，授权后也不在本命令里改 workspace——交给 `/crate` 对抗审查。

## 前置：安全网

先运行项目已有的最小相关测试并记录基线；无可用安全网时，只做机械可证的删除，行为重构先补一个关键契约测试。pub API 保持不变；确要收缩 pub 面（SIMP-03）单独列出请用户批准。

热核落地（只在本命令 `--apply` 后改码，`review` 永远不改）：优先 **删整层/整枝**，不要把同样的 if 链收进一个 helper 就算完成。可见 judo（SIMP-09..12）比去 builder 仪式更优先。

## 五遍扫描（每处改动标注规则号）

0. **judo**：整枝条件/整层转发能否消失？特判能否变成默认路径（SIMP-10）？文件被推过 1000 行则先按 WS-11 分解（SIMP-09），不拆 crate。
1. **死码与死依赖**：`cargo +nightly udeps` 或 cargo-machete 查无用依赖；`#[allow(dead_code)]` 逐个清算；从未被读的字段、从未失败的错误变体。
2. **塌层**（SIMP-01/02）：单实现 trait、转发 wrapper 或单调用方通用函数先做删除测试：删后若复杂度只是散回调用方则保留；若复杂度消失才内联。
3. **去仪式**（SIMP-06）：builder/getter/setter/成对 API 只有在未编码约束、未保护兼容面且不减少调用方复杂度时删除；不以复用次数机械裁决，也不为少几行扩大 pub 字段。
4. **去分配**（SIMP-04/05）：只清理可证明无收益的中间集合与 clone；循环和迭代器按清晰度选择。`dyn`、泛型和 enum 依据开放性、编译成本与异构需求选择。
5. **结构梯子**（WS-11 / D-1）：按函数 → `mod` → crate 评估，**不按行数**。
   - 函数过长（clippy `too_many_lines` 信号）→ 抽函数，留在同文件。
   - 同一文件两个不变量 / 两套夹具 / 两段变化原因 → 候选拆 `mod`（可在本命令 `--apply` 后做，行为不变）。
   - 独立编译、第二调用方、发布隔离 → **只列入「建议跑 `/crate <路径>`」**，本命令不改 `Cargo.toml`、不新建 crate（CK-06 / WS-12）。
   - 单调用方、转发层、生成代码、测试表 → 保留并写理由。

## 验证与输出

按 [kernel/finding.md](../kernel/finding.md) 组织：一句话结论 → 范围行 → 正文 → 验证 → 置信度 → 下一步 → 写授权收尾。

- **只读**：跑（或声明未跑）最小相关测试基线 → 候选表（位置｜动作｜规则｜可安全/须批准/建议 `/crate`）→ 保留项理由 → 无 LOC delta。完成条件：候选与保留项覆盖五遍扫描，未改码，未改 workspace。
- **写入授权后**：每批后运行最小相关检查；结束时运行项目已有 lint/test 门禁。公共行为不变由契约测试或机械等价证据背书。

```
LOC：<前> → <后>（-N% 或 未改/待授权）   层级：删 trait <n> / wrapper <n> / builder <n>   依赖：-<n>
| 位置 | 改动或候选 | 规则号 |
```

保留项（审视过但不动的抽象）单独一行说明理由——精简不是拆到裸奔，是**每一层都付得起解释成本**。残余默认输出为 RUST.md 债务候选，显式 `--record` 才写入。
