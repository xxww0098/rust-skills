# 读火焰图

目的：从一张图里只点名**一个**该改的 self 帧。宽度是 inclusive 时间，高度几乎无信息。

## 怎么看

1. 底边从左到右 = 一次运行。一条框的**宽度** = 它和子帧合计占用的采样。
2. **inclusive（框宽）**：该函数 + 它调用的一切。
3. **self（框宽 − 子框宽）**：函数自己的活。优化只认 self，除非 inclusive 宽而 self 窄——那是调用了热子帧，应点名子帧。
4. 平台塔（`hashbrown` / `regex` / `serde` / `drop_in_place` / allocator）要翻译成**你的代码哪一行把它叫进来**，不要去改标准库。

## 合法结论

写出三行，否则不算读完：

```
self 符号：<demangled>
调用方：<你的 crate 里的函数 / 文件:行>
假设：<为什么它不该这么宽；要改的不变量>
```

多峰：只点最宽的那一个 self。第二名留给下一轮循环。

## 常见误读

| 看到 | 不是 | 才是 |
|---|---|---|
| 又高又瘦 | 最热 | 调用深，时间短 |
| `memcpy` / `drop` 很宽 | 去手写 SIMD | 多余 clone / 过大结构 / 逃逸分配 |
| `regex::Regex::new` 很宽 | 换引擎 | 热路径重复编译，应 `OnceLock` |
| 全是 `[unknown]` | 猜函数名 | 回 [profile.md](profile.md) 修符号 |
| 与上次不同机 / 不同命令 | 变快了 | 作废（PERF-01） |
